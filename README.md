# AI Mini Projects

A collection of small AI-powered Python projects for practice and portfolio — built with Streamlit and various AI APIs.

## Projects

- [`thumbnail-generator`](./thumbnail-generator) — generates thumbnail images from a text prompt using Hugging Face's Inference API
- [`seo-optimizer`](./seo-optimizer) — analyzes content for SEO metrics and gives AI-powered improvement suggestions
- [`parlour-bot`](./parlour-bot) — Gemini-powered chatbot that answers a beauty parlour's customer questions about services, prices, and timings
